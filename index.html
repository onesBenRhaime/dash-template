FAQ

Questions ops leaders ask first.

What happens if an agent makes a bad call?

Anything above Draft is logged with its reason, the data it used and who approved it. You can override any decision, and overrides with reasons teach the agent. If something looks systematically wrong, pause one agent or all of them in one click.

Can agents break hours-of-service or customer windows?

No. Guardrails are hard limits enforced outside the model. An agent can propose crossing one, but the action is blocked and routed to a person, exactly as you saw in the sandbox.

Which systems does FleetFlow connect to?

Common TMS, ELD and WMS platforms out of the box, plus email, SMS and Slack for notifications. Agents read through scoped, read-only connections unless a capability explicitly allows writes.

How long does it take to go live?

Most teams connect data in a day and run every agent in Observe mode for a week. Then they use the sandbox to raise autonomy one capability at a time.
